- `duplicate` — byte-identical copy of the file named in `duplicate_of`, not loaded by the runtime.
- `unreferenced` — project-authored file nothing points at; review before keeping.

## Verified legend

- `real_export` — a genuine TIA export (ground truth for that version).
- `schema_spec` — official XSD; proves element order/enums, not runtime behaviour.
- `official_api_doc` — official Openness assembly + XML doc.
- `official_install_file` — auxiliary file shipped with the TIA install (PDF, .bat, etc.).
- `fragment` — hand-authored XML fragment, not an export; never cite it as ground truth.
- `project_note` — project-authored note, not a TIA export.
- `see docs/samples/manifest.json` — sample provenance/status is per file; this index does not duplicate it.
